САЙТ «ДЛЯ МОЕЙ ЛЮБИМОЙ АЛИ» ❤️

КАК ДОБАВИТЬ ФОТОГРАФИИ
1. Открой папку images.
2. Замени примеры/добавь свои фотографии в формате JPG.
3. Названия файлов должны быть строго такими:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   ...
   photo12.jpg
4. Если фотографий меньше 12, оставшиеся карточки будут показывать красивую заглушку.
   Лучше использовать вертикальные фотографии хорошего качества.

КАК ДОБАВИТЬ МУЗЫКУ
1. Открой папку music.
2. Положи туда аудиофайл песни.
3. Назови его music.mp3.
4. На сайте Аля сможет включить музыку кнопкой «Музыка».
   На iPhone музыка не запускается автоматически без нажатия — это ограничение Safari.

КАК ИЗМЕНИТЬ ДАТУ ОТНОШЕНИЙ
Дата сейчас установлена на 29 августа 2026 года.
Она находится в начале файла script.js:
const START_DATE = new Date(2026, 7, 29, 0, 0, 0);
Месяц 7 означает август (в JavaScript январь = 0).
Счётчик считает 29 августа первым днём отношений.

КАК ОТКРЫТЬ САЙТ НА КОМПЬЮТЕРЕ
Можно просто дважды нажать index.html. Для проверки музыки и фотографий лучше использовать VS Code + расширение Live Server.

КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES
1. Создай новый публичный репозиторий на GitHub, например love-for-aliya.
2. Загрузи в репозиторий ВСЕ файлы и папки из этой папки.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. В Branch выбери main и папку /(root), затем Save.
6. Подожди немного — GitHub покажет ссылку на сайт.

ВАЖНО
- Не переименовывай index.html, style.css и script.js.
- Папки images и music должны находиться рядом с index.html.
- Названия файлов чувствительны к регистру: photo1.jpg и Photo1.jpg — разные имена.
- Если используешь PNG или HEIC, лучше предварительно преобразовать фотографии в JPG.
- Внешний шрифт загружается из Google Fonts; если интернета нет, сайт использует системные шрифты.
- Сайт статический, никаких аккаунтов, паролей и серверной базы не требует.
